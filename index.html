APawtMent System Manual & Button Guide

Step-by-step procedure on how every section, feature, and button works.

1. Header Buttons & Controls

🔒 / 🔓 Admin Toggle Button:

Click to log in to Admin Mode using the password admin123. Unlocking Admin Mode enables the Edit Logs Table spreadsheet editor.

☀️ / 🌙 Theme Toggle Button:

Instantly switches between Dark Mode and Light Mode. Your choice is saved automatically.

❓ System Manual Button:

Opens this interactive System Manual & Step-by-Step Procedure popup anytime.

➕ Add Test Case Button:

Opens the single test case logging form for Testers and Fur Parents to record a new test scenario run.

📊 Edit Logs Table Button (Admin Only):

Opens the full-screen spreadsheet editor (Excel-style) to edit or add multiple test logs simultaneously.

2. Dashboard Analytics Cards

  • Total Logged: Live counter of all test scenarios stored in Supabase.
  • Passed Tests: Count and percentage of test runs with status PASS.
  • Failed / Bugs Found: Count and percentage of test runs with status FAIL.
  • Success Rate Ring: Dynamic SVG progress ring illustrating overall QA pass rate.

3. Toolbar Search, Filters & Data Actions

  • Search Bar: Type keywords to filter logs by Test ID, Module name, Scenario, Steps, or Comments.
  • Module Filter: Filter logs by screen/feature (e.g. Login Form, Profile, Reports, AI Page, QR Scanner).
  • Status Filter: Show All Statuses, PASS only, or FAIL only.
  • User Role Filter: Filter by Admin, Sub-Admin (Staff), Sub-Admin (Vet), or Fur Parent.
  • Data Actions Menu:
    • Export CSV: Download test logs as a .csv file for Excel or Google Sheets.
    • Export JSON: Backup test data as a .json file.
    • Import JSON: Restore test logs from a local backup file.
    • Reset Store: Restore default 18 Capstone seed test logs in Supabase.

4. Step-by-Step Operating Procedures

Step 1: Unlocking Admin Mode

  1. Click the 🔒 Lock Icon in the top-right header.
  2. Enter password admin123 into the dialog.
  3. Click Verify Credentials. The icon turns green 🔓.

Step 2: Adding a New Test Log

  1. Click ➕ Add Test Case in the header.
  2. Fill in Module, Test Scenario, Test Steps, Expected Result, User Role, and Status.
  3. Click Add Test Case to save directly to Supabase.

Step 3: Toggling PASS/FAIL Status

  1. Locate the test row in the main registry table.
  2. Click directly on the green PASS or red FAIL badge.
  3. The status updates instantly in Supabase and recalculates success rate metrics.
